## Criteria that gets evaluated

- **Engineering fundamentals:** code structure, API design, data modelling, and correctness.
- **Problem solving:** how you handled ambiguity, what you chose to prioritize, and why.
- **AI feature integration:** prompt and request design, and how you handled unexpected, low quality, or adversarial input, such as injected instructions in resume text.
- **Test quality:** whether tests meaningfully exercise core logic and AI integration rather than existing to inflate a coverage number.
- **Judgment in using AI tools:** shown in your AI usage log. Explain when you accepted, corrected, or overrode the tool's output.
- **Learning ability:** shown in your learning log for the unfamiliar component. Explain how you approach something new and how you'd hand it off to someone else.
- **Cloud and deployment reasoning:** either a working deployment or a sound one page design with sensible named services and a realistic cost range.
- **Communication:** clarity of the README and write-up. Could someone else pick this up?
- **Explain your decisions. We're reading your write-up as closely as your code. “I chose X because Y, and traded off Z” is what we're looking for.**

Make sure that I am communicating these points clearly.
